# FitAssist — персональный фитнес-ассистент

## Назначение приложения

Приложение помогает вести дневник тренировок, отслеживать прогресс и
нагрузки, а также получать персональные рекомендации от ИИ-модуля на
основе истории тренировок и целей пользователя.

## Основные пользовательские сценарии

1. **Просмотр сводки** — пользователь видит ключевые метрики (число
   тренировок, общий объём, время, серия дней) и последние тренировки.
2. **Работа с тренировками** — просмотр списка тренировок, открытие
   детальной страницы с упражнениями и подходами.
3. **Каталог упражнений** — поиск упражнений по названию и группе мышц.
4. **Анализ прогресса** — график динамики объёма нагрузки и веса тела,
   личные рекорды по ключевым упражнениям.
5. **Рекомендации ИИ** — просмотр персональных советов по нагрузке,
   восстановлению, питанию и технике.
6. **Профиль** — редактирование личных данных и цели тренировок.
7. **Аутентификация** — вход в приложение и выход.

## Экраны

| Маршрут | Назначение |
|---|---|
| `/login` | Вход / регистрация |
| `/dashboard` | Сводка и последние тренировки |
| `/workouts` | Список тренировок |
| `/workouts/:id` | Детали тренировки (упражнения, подходы) |
| `/exercises` | Каталог упражнений с поиском |
| `/progress` | График прогресса и личные рекорды |
| `/recommendations` | Карточки рекомендаций ИИ |
| `/profile` | Профиль пользователя |
| `*` | Страница 404 |

## Стек (frontend, этап ЛР №1)

- **React 18** + **TypeScript** + **Vite**
- **React Router v6** — клиентская маршрутизация
- **Mantine v7** — библиотека UI-компонентов
  - `@mantine/core` — базовые компоненты
  - `@mantine/form` — работа с формами и валидацией
  - `@mantine/charts` (на базе Recharts) — графики
  - `@mantine/notifications` — уведомления
  - `@tabler/icons-react` — иконки
- **dayjs** — работа с датами (транзитивно для `@mantine/dates`)

На этапе ЛР №1 используются **демонстрационные данные** из
`src/shared/mocks/data.ts`.

## Структура frontend

Структура близка к упрощённому Feature-Sliced Design:
src/
├─ app/ # настройка приложения: тема, роутер, layout
├─ pages/ # страницы приложения
└─ shared/ # общие ресурсы: моки, стили, UI-компоненты
├─ mocks/ # демонстрационные данные
├─ styles/ # глобальные стили
└─ ui/ # переиспользуемые компоненты

## Как запускать Front
**Установка зависимостей:**
 - npm install
**Запуск dev-сервера:**
 - npm run dev
Приложение откроется на http://localhost:5173/
**Сборка production-версии:**
 - npm run build
 - npm run preview
